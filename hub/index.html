📖 CardioNav — Quick Help

  1. Pick a disease and cell state from the top selectors (AF / CAD / AVS × 65 cell states each).
  2. Read the graph: outer ring = seed genes (GWAS-prioritised), middle ring = ATAC peaks (regulatory regions), inner ring = TFs. Edges go TF → peak → gene.
  3. Click a SNP / peak to see the credible-set details: rsid, PIP, gnomAD AF, OT study_id, VEP consequence, L2G top gene.
  4. Set your LLM key via the Activate Agent button (Anthropic sk-ant-… or Gemini AIza…). Stored in your browser only.
  5. Ask in the chat panel: questions, view switches ("show TBX5 in atrial cardiomyocytes"), PMID lookups. Citations arrive inline with 🟢/🟡/⚪/🔴 confidence pills.
eGRN
Disease + cell-state specific predicted regulatory network (TF → peak → gene). Hypotheses, not experimentally confirmed interactions.
GWAS-z
The score colouring seed-gene and TF nodes. Computed by SNP2CELL network propagation from the disease-specific GWAS sumstats: SNP-level Z-scores are mapped to genes via fine-mapping + L2G, then diffused through the gene-regulatory network so that each node ends up with an aggregated, propagation-smoothed disease-relevance score. Higher = more strongly implicated by the GWAS signal in this cell-state's regulatory neighbourhood.
PIP
Posterior Inclusion Probability — credible-set membership weight within one fine-mapping run. PIP 0.8 ≠ "80% causal"; it means 80% of the posterior in that credible set sits on this SNP. Different studies of the same locus can produce different PIPs — that's why the SNP card shows study_id.
DE-z
Differential expression Z-score relative to the reference cell state you pick at the top. Not absolute expression. Switch the reference to see how specificity changes.
AlphaGenome (beta)
Deep-learning regulatory variant-effect prediction. Only 15 representative SNPs are pre-computed here. Absent in cache ≠ "no predicted effect" — just "not yet scored".
Confidence pill / Vote-curated knowledge
🟢 high = ≥ 2 human net up-votes. 🟡 medium = 1 vote or agent recurrence ≥ 2. ⚪ low = no signal yet. 🔴 flagged = users down-voted, excluded from grounding. "Verified" badge means PMID exists, NOT that the paper supports the claim. Always read citations before quoting.
  • Find TF candidates at a locus → search the seed gene, click it, follow edges inward to peaks → TFs.
  • Pivot a SNP across diseases → search by rsid, click the cross-payload hit you want to switch to.
  • Test how a gene's specificity depends on reference → switch the reference cell-state dropdown, watch DE-z colour shift.
  • Build a literature digest for a claim → ask chat, then 👍 the PMIDs you've read. After net ≥ 2 votes, click 📝 Summarize to save the abstract digest as durable prior knowledge for future chats in this context.
  • Check AlphaGenome predictions → click 🧬 on a SNP card. If your variant isn't in the beta cache, the panel lists the 15 that are.

CardioNav can mislead if these traps are not understood:

  • "Verified" citation ≠ paper supports the claim. The badge confirms the PMID exists on PubMed and that the LLM linked it. A topically-unrelated paper can still pass. Read the abstract before quoting anything in a grant.
  • PIP is per fine-mapping run, not per locus. A SNP at PIP 0.8 in one credibleSet may be at PIP 0.1 in another study for the same trait. The SNP card now shows the OT study_id that produced the PIP — use it for round-trip traceability.
  • eGRN edges are predicted, not validated. A "TF→peak→gene" edge means the pipeline saw motif + chromatin + co-expression consistency, not that a ChIP-seq or CRISPRi experiment confirmed the interaction.
  • DE-z depends on the reference. Switching the reference cell-state changes which genes light up. A gene that looks specific to atrial cardiomyocytes vs "all" may not look specific vs "ventricular cardiomyocytes". Sanity-check with at least 2 references before claiming specificity.
  • AlphaGenome beta covers 15 variants only. "Variant not in beta cache" means we haven't scored it yet — NOT that AlphaGenome predicts zero effect.
  • Cached refs ≠ user-curated knowledge. The backend silently caches every cited PMID by context for retrieval speed; this is an internal store. Only the explicit 👍 vote + 📝 Summarize flow is human-curated.
Why is the chat so slow / why does it say I'm rate-limited?
Each chat call sends 15-30k input tokens (system prompt + graph state + history). Gemini 2.0-flash free tier is 1M tokens/min — heavy use can exhaust this in a handful of rapid-fire questions. Wait 60 s and retry, or upgrade your Google AI / Anthropic plan.
I see "service overloaded (503)" — did I burn my quota?
No. 503 is on Google's side (especially during peak hours); no quota is consumed. Just retry in 30 s.
My gene isn't on the graph.
The seed ring shows the top-N by GWAS-z. If your gene didn't make the cut for this (disease, cell-state) combo, raise the top-N slider. If still absent, your gene was below the upstream pipeline's union-seed threshold.
The SNP card shows multiple study_id_candidates.
This SNP appears in multiple Open Targets credibleSets that all match the trait label. The payload can't pick one unambiguously from the trait string alone — both / all are listed for you to choose.
The agent ignored my view switch instruction.
The agent emits structured actions like set_disease / set_target_cs that the viewer applies automatically. If you only see prose, the LLM hallucinated the format — retry with a more explicit phrasing: "switch the view to disease=AF, target_cs=AtrialCardiomyocytesLeft".
