How to use

Pick disease + target cell_state. Default specificity contrast is "vs all other cell_states". Switch to Selected cell_states to pick a custom reference subset. Click a node to pin annotation (draggable panel) and add it to the trail (yellow). Hover brings the closest node to the front; press Tab to cycle stacked nodes. Re-click removes the node's exclusive contribution. Empty-space click clears.
